ExpenSense

Description

ExpenSense (“the agent makes sense of your expenses intelligently”) is a multi-agent enterprise expense management platform designed to streamline and automate the entire reimbursement lifecycle. The system integrates traditional backend services with specialized AI agents to provide accurate, policy-compliant, and auditable expense processing at scale. At its core, ExpenSense replaces manual review and inconsistent human decision-making with a coordinated network of AI-powered components, each responsible for a distinct part of the workflow. The architecture incorporates an Expense Agent, Document Agent, Email Agent, and an Orchestrator Agent, all working together to parse receipts, validate policy compliance, detect anomalies, and determine reimbursement outcomes. The system is built with a layered architecture that separates presentation, business logic, agent reasoning, and data access. Users interact with a modern web interface for submitting expenses, querying policy information, viewing submission history, and managing their account and financial details. Authentication and authorization are enforced before any user gains access to sensitive operations, ensuring compliance with enterprise security standards. ExpenSense enforces a comprehensive reimbursement policy through a combination of rules-based logic and semantic reasoning. Automated approval, frequency violation detection, document validation, and large-amount flagging are implemented through the Expense Agent, enabling the system to handle routine submissions instantly while routing higher-risk requests to human administrators. By combining agent-based intelligence, robust backend infrastructure, and clear policy enforcement, delivers a scalable, secure, and accountable reimbursement workflow suitable for enterprise environments. The result is a system that not only reduces operational overhead and speeds up approval times but also significantly improves consistency, fairness, and policy alignment across all submitted expenses. Since the API credits necessary for the ExpenSense Agent to run costs money, it is currently disabled. The code for the agent is available at my github repository. It, along with the README, gives insight into how the agent was built and how it functions. Github Link: https://github.com/joshlee5/ExpenSense-AI-Project

Saphire SAT Practice App

Description

Saphire SAT Practice App is a web and mobile application that offers students convenient SAT practice that can be done anytime, anywhere! It provides a variety of study modes, such as timed, to answer multiple-choice questions in reading or math. Instantaneous feedback is offered to the user upon getting a question wrong, and their history is stored in our database so that the app can see where they are at in each subject and recommend different areas of focus in their study habits. The app is built in Flutter using the Dart package to create accessibility on all platforms. It utilizes Google Firestore to store not only user information but also their question and answer history. This allows the app to adapt to their subject knowledge and make recommendations to users on how to best use their time to prepare for the SAT. The current app is in its MVP phase so not all study modes and question adaptibility has been implemented. Github Link: https://github.com/joshlee5/Saphire-SAT-Practice-App

LetterBooksd

Description

An IOS app for reviewing books similar to how Letterboxd is for reviewing movies. It utilizes a Google Firebase to store Google Books API data of the descriptions of various books that users can search up. They can leave reviews for these books and users can comment on reviews as well. Github Link: https://github.com/joshlee5/LetterBooksd.git
